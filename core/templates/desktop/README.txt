تطبيق سطح مكتب مُولَّد بمحرك ترجمة EE#
======================================

البناء:
  cmake -S . -B build -DEE_CORE_DIR=/مسار/EEsharp/core
  cmake --build build -j
  ./build/app

- program.ee : برنامجك (المصدر الأصلي).
- main.cpp   : مُولَّد؛ يضمّن البرنامج داخل ملف تنفيذي واحد ويركّب «الصدفة» لسطح المكتب.
- الصدفة في سطح المكتب: $صدفة_ملف_اقرأ / $صدفة_ملف_اكتب / $صدفة_نظام / $صدفة_بيئة /
  $صدفة_خزن / $صدفة_اقرأ_مخزن / $صدفة_انتظر / $صدفة_كرر_كل / $صدفة_سجل / $صدفة_تنبيه.
  تنبيه أمني: $صدفة_نظام تنفّذ أوامر النظام بصلاحيات مستخدمك؛ لا تشغّل برامج لا تثق بها.
