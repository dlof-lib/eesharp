# EE# — لغة برمجة عربية بالكامل

**EE#** لغة برمجة كلماتها المفتاحية ودوالها ورسائل أخطائها بالعربية، ومفسّرها مكتوب بـ **C++17**.
يرافقها محرر أكواد لأندرويد (**Java + XML**) وسير عمل **GitHub Actions** يبني ملف APK تلقائياً.

```
EEsharp/
├── core/        مفسّر EE# بلغة C++ (محلل لفظي ← نحوي ← منفّذ) + واجهة سطر الأوامر
├── android/     محرر الأكواد: Java + XML + جسر JNI إلى المفسّر
├── examples/    برامج تجريبية
├── tests/       اختبارات (برنامج + ناتج متوقع)
└── .github/workflows/android.yml   بناء المفسّر والاختبارات وملف APK
```

## ثلاث علامات تكفي لقراءة أي كود

| الشيء | كيف يُكتب | مثال |
|---|---|---|
| **المفهوم** (دالة أو أمر) | يبدأ بـ `$` | `$اعرض` ، `$جمع` |
| **المتغير** | بين `<<` و `>>` | `<<الاسم>>` |
| **القيمة** | نص بين علامتي اقتباس، أو رقم | `"مرحباً"` ، `٣٫٥` |

وكل كتلة (شرط، حلقة، مفهوم، برنامج) تنتهي بكلمة واحدة: **`نهاية`**، ويُستحسن تسميتها بنوع الكتلة: `نهاية لو` ، `نهاية كرر` ، `نهاية لكل` ، `نهاية مفهوم` ، `نهاية برنامج`.

```
برنامج مثال

// تعليق
متغير <<الاسم>> = "سارة"
$اعرض "أهلاً", <<الاسم>>

مفهوم $مضروب(<<ن>>)
  لو <<ن>> اصغر من او يساوي 1
    ارجع 1
  نهاية لو
  ارجع <<ن>> * $مضروب(<<ن>> - 1)
نهاية مفهوم
$اعرض $مضروب(5)          // 120

لو <<الاسم>> = "سارة"
  $اعرض "مرحباً سارة"
والا لو <<الاسم>> = "أحمد"
  $اعرض "مرحباً أحمد"
والا
  $اعرض "من أنت؟"
نهاية لو

متغير <<ن>> = 0
كرر <<ن>> اصغر من 3
  <<ن>> += 1
نهاية كرر

لكل <<ع>> في [3، 1، 2]
  $اعرض <<ع>>
نهاية لكل

نهاية برنامج
```

### قواعد الكتابة

- **كل جملة في سطر.** وللجمل القصيرة على سطر واحد افصل بينها بـ `؛` : `متغير <<أ>> = 1؛ متغير <<ب>> = 2`.
- **الأمر بلا أقواس:** `$اعرض "نص", <<س>>` ، أو بأقواس مع إمكانية التداخل: `$اعرض($جمع(1, 2))`.
- **التعريف:** `متغير <<س>> = 5` ثم الإسناد `<<س>> = 6` أو `<<س>> += 1`.
- **المفهوم:** `مفهوم $جمع(<<أ>>, <<ب>>)` أو بلا أقواس `مفهوم $جمع <<أ>>, <<ب>>` ... `نهاية`.
  يمكن تمرير المفهوم كقيمة بكتابته بلا أقواس: `متغير <<ف>> = $جمع` ثم `<<ف>>(1, 2)`.
- **مفهوم مجهول:** `متغير <<مربع>> = مفهوم(<<س>>) ارجع <<س>> * <<س>> نهاية`.
- **غلاف البرنامج (اختياري):** `برنامج الاسم` في البداية و`نهاية` في آخر الملف، فتصبح بداية الكود ونهايته واضحتين.
- **النهايات المسمّاة:** التسمية اختيارية لكن اللغة تتحقق منها: `نهاية كرر` على كتلة `لو` خطأ واضح يذكر الكتلة المفتوحة وسطرها. وفي سلسلة `لو ... والا لو ... والا` نهاية واحدة `نهاية لو` تغلقها كلها.
- **الأخطاء المفيدة:** إذا نسيت العلامة تخبرك الرسالة بالصيغة الصحيحة، وإن نسيت `نهاية` تذكر أي كتلة (وفي أي سطر) لم تُغلق وما النهاية المطلوبة.

### الكلمات المفتاحية

| الكلمة | المعنى |
|---|---|
| `متغير` | تعريف متغير |
| `لو` (أو `اذا`) / `والا لو` / `والا` | شرط. السلسلة كلها تنتهي بـ `نهاية` واحدة |
| `كرر` (أو `طالما`) | حلقة while |
| `لكل <<س>> في ...` | حلقة على قائمة أو نص |
| `مفهوم` (أو `دالة`، `وظيفة`) | تعريف مفهوم (دالة) |
| `ارجع` | إرجاع قيمة |
| `توقف` / `استمر` | break / continue |
| `صح` `خطأ` `عدم` | true / false / null |
| `و` `او` `ليس` | and / or / not |
| `برنامج` ... `نهاية` | غلاف البرنامج (أو `ابدأ` ... `انتهى`) |

الهمزات اختيارية في الكلمات المفتاحية (`اذا` = `إذا`، `او` = `أو`، `والا` = `وإلا`).

### المقارنة بالكلمات

| بالكلمات | الرمز |
|---|---|
| `<<س>> اكبر من 3` | `<<س>> > 3` |
| `<<س>> اصغر من 3` | `<<س>> < 3` |
| `<<س>> اكبر من او يساوي 3` | `<<س>> >= 3` |
| `<<س>> اصغر من او يساوي 3` | `<<س>> <= 3` |
| `<<س>> = 3` | `<<س>> == 3` |
| `<<س>> لا = 3` أو `<<س>> لا يساوي 3` | `<<س>> != 3` |

و`ليس` تنفي المقارنة كاملة: `ليس <<س>> = 3` تعني `ليس (<<س>> = 3)`. الرموز `== != < > <= >=` تعمل أيضاً، والكلمة `يساوي` ما زالت مقبولة كمرادف للعلامة `=`.

### العلامة `=`: إسناد أم مساواة؟

- **في بداية الجملة** `=` تعني **إسناداً**: `<<س>> = 5` و`<<ق>>[0] = 9` و`متغير <<س>> = 5`.
- **داخل أي تعبير** (شرط، وسيط، قيمة) `=` تعني **مساواة**: `لو <<س>> = 5` و`$اعرض <<س>> = 5` و`كرر <<ن>> = 0`.
- وبعد علامة الإسناد يُقرأ الباقي تعبيراً، فـ `<<س>> = <<أ>> = <<ب>>` تعني: ضع في `<<س>>` نتيجة مقارنة `<<أ>>` بـ `<<ب>>`.

### رموز الحساب والإسناد

| الرمز | معناه | مثال |
|---|---|---|
| `+` `-` `*` `/` `%` | جمع، طرح، ضرب، قسمة، باقي | `<<س>> + 1` |
| `×` `÷` `−` `٪` | ضرب، قسمة، طرح، باقي (بدائل رياضية) | `٦ × ٧` ، `<<س>> ÷ 4` |
| `≠` `≤` `≥` | `!=` و`<=` و`>=` | `<<س>> ≥ 16` |
| `=` ، `←` | إسناد في بداية الجملة | `<<س>> = 5` ، `<<س>> ← 5` |
| `+=` `-=` `*=` `/=` `%=` | إسناد مركّب | `<<س>> += 1` |
| `×=` `÷=` `−=` `٪=` | إسناد مركّب بالرموز الرياضية | `<<س>> ×= 2` |
| `$` | بداية المفهوم | `$اعرض` |
| `#` | تعليق (مثل `//`) | `# ملاحظة` |

### تفاصيل عربية

- الأرقام العربية الهندية تعمل: `٣ + ٤٫٥`
- الفاصلة العربية `،` والفاصلة المنقوطة `؛` تعملان مثل `,` و `;`
- النصوص: `"..."` أو `'...'` أو `“...”` أو `«...»`
- التعليقات: `// ...` أو `# ...` أو `/* ... */`
- **الشرطة السفلية `_`** تفصل كلمات الاسم الواحد في المتغيرات والمفاهيم: `<<اسم_المستخدم>>` و`<<عدد_المحاولات>>` و`$مجموع_الأعداد`. الأسماء بأي حروف عربية أو لاتينية وأرقام و `_`، وتبدأ بحرف.
  والمسافة داخل `<< >>` غير مسموحة، وتقترح لك الرسالة الاسم الصحيح: `<<اسم المستخدم>>` ← `<<اسم_المستخدم>>`.

### الأنواع والعمليات

أرقام، نصوص، منطقي، قوائم، مفاهيم، عدم. العمليات: `+ - * / %` و `== != < > <= >=` و `+= -= *= /= %=`.
`+` يجمع الأرقام ويدمج النصوص والقوائم، و `"ab" * 3` تكرر النص. الفهرسة تبدأ من 0 ويقبل `<<ق>>[-1]` للأخير.

### المفاهيم المدمجة

| المفهوم | الوصف |
|---|---|
| `$اعرض ...` (أو `$اطبع`) / `$اكتب ...` | طباعة مع سطر جديد / بدونه |
| `$اسأل "سؤال"` / `$اسأل_رقم "سؤال"` (أو `$اقرأ` / `$اقرأ_رقم`) | قراءة سطر / رقم من المدخلات |
| `$طول(x)` | طول نص أو قائمة |
| `$اضف(ق, v)` / `$ازل(ق)` | إضافة / إزالة آخر عنصر |
| `$مدى(أ)` `$مدى(أ، ب)` `$مدى(أ، ب، خطوة)` | قائمة أرقام |
| `$جذر` `$اس` `$مطلق` `$ارضية` `$سقف` `$تقريب` `$اكبر` `$اصغر` | رياضيات |
| `$نص(x)` `$رقم(x)` `$نوع(x)` | تحويل وفحص |
| `$قص(نص، من، الى)` `$عكس(x)` `$فرز(ق)` `$يحتوي(x، y)` | نصوص وقوائم |
| `$عشوائي()` `$عشوائي(أ، ب)` | أعداد عشوائية |
| `$ارقام_عربية(x)` | تحويل الأرقام إلى ٠١٢٣… |
| `$كبير` `$اس_كبير` `$اس_بالباقي` `$اولي_كبير` | الأعداد الكبيرة (انظر القسم التالي) |
| `<<باي>>` | المتغير الثابت π |

## الأعداد الكبيرة (بلا حدّ للأرقام)

الأرقام العادية تدقّ حتى ١٥ خانة تقريباً. أما `$كبير` فيعطيك **عدداً صحيحاً بحجم لا يحدّه إلا الذاكرة** (حتى مليون خانة)،
وخلفه في C++ صنف `BigInt` كامل: جمع وطرح، ضرب، **قسمة طويلة**، أسّ سريع، **أسّ بالباقي**، واختبار أولية **Miller–Rabin**.
وكلها تُكتب هنا في أسطر قليلة:

```
متغير <<ناتج>> = $كبير(1)
لكل <<ع>> في $مدى(1, 101)؛ <<ناتج>> *= <<ع>>؛ نهاية لكل
$اعرض "١٠٠! =", <<ناتج>>
$اعرض "عدد خاناته:", $طول($نص(<<ناتج>>))
```

| المفهوم | الوصف |
|---|---|
| `$كبير(x)` | يحوّل رقماً صحيحاً أو نصاً من أرقام إلى عدد كبير |
| `$اس_كبير(أ، ن)` | `أ` مرفوعاً للأس `ن` بدقة كاملة |
| `$اس_بالباقي(أ، ن، م)` | `أ^ن` باقي القسمة على `م` (أساس RSA) دون تضخم الأرقام |
| `$اولي_كبير(x)` | هل العدد أولي؟ |

- العمليات `+ - * / % < > = ...` تعمل عليه وعلى الأرقام الصحيحة العادية؛ والناتج عدد كبير.
- `/` و`%` على الأعداد الكبيرة **قسمة صحيحة** (القاطعة نحو الصفر): `-7 / 2` تعطي `-3` وباقيها `-1`.
- أي رقم صحيح يزيد على ١٥ خانة يُقرأ تلقائياً عدداً كبيراً: `متغير <<س>> = 123456789012345678901234567890`.
- لا يُخلط مع الأرقام العشرية في الحساب (تظهر رسالة تطلب `$كبير`)، ويمكن مقارنته بها. `$رقم(x)` يعيده رقماً عادياً، و`$نوع(x)` يعطي `عدد_كبير`.
- أمثلة جاهزة في `examples/`: `factorial_big.ee` و`digit_sum_pow.ee` و`fibonacci_big.ee` و`mersenne.ee` و`rsa_toy.ee`.

## بناء المفسّر وتشغيله (Linux / macOS)

```sh
cmake -S core -B build && cmake --build build -j
./build/ee examples/hello.ee
ctest --test-dir build --output-on-failure
```

## تطبيق أندرويد

محرر بتلوين للصيغة، وخانة مدخلات، وزرا تشغيل وإيقاف، وفتح/حفظ الملفات، وحفظ تلقائي. لا يعتمد على أي مكتبات خارجية.

- **شريط الرموز:** أزرار لإدراج `$` و`<< >>` و`" "` (يوضع المؤشر داخلها تلقائياً) والكلمات المفتاحية.
- **إغلاق تلقائي:** كتابة `(` أو `[` أو `"` أو `<<` تضيف المغلِق وتضع المؤشر بينهما، وكتابة المغلِق فوق مغلِق موجود تتخطّاه بدل تكراره (لا تتكرر `)` ولا `>>`).
- **نهاية تلقائية:** عند ضغط Enter بعد سطر يفتح كتلة (`لو` أو `كرر` أو `لكل` أو `مفهوم`) تُضاف الإزاحة وتُكتب تحتها `نهاية لو` (أو نوع الكتلة)، والمؤشر في مكانه داخل الجسم. ولا تُكرَّر إن كانت النهاية موجودة أصلاً.
- **تنسيق:** زر «تنسيق» يرتّب إزاحة الكود حسب الكتل ويسمّي كل `نهاية` عارية بنوع كتلتها.
- **سمتان:** فاتحة بخلفية دافئة هادئة، وداكنة بألوان ناعمة. زر «◐ السمة» للتبديل ويُحفظ اختيارك.
- **تلوين:** كل نوع بلون: المفاهيم `$` والمتغيرات `<< >>` والنصوص والأرقام والكلمات المفتاحية؛ والفواصل باهتة والتعليقات خافتة.

- **من GitHub:** ادفع المشروع إلى مستودع. تبني الـ Action ملف APK وتجده في صفحة التشغيل ضمن *Artifacts*. وعند دفع وسم مثل `v0.1.0` يُرفق الملف تلقائياً بصفحة *Releases*.
- **محلياً:** افتح مجلد `android/` في Android Studio (سينشئ Gradle wrapper تلقائياً) وشغّل `app`.
  أو من سطر الأوامر مع Gradle 8.7 وJDK 17 وNDK 26: `cd android && gradle assembleDebug`.

> الـ APK الناتج من `assembleDebug` موقّع بمفتاح التطوير ويُثبَّت مباشرة على الهاتف. للنشر على المتاجر أضف إعداد توقيع Release.
