# EE# — لغة برمجة عربية بالكامل

**EE#** لغة برمجة كلماتها المفتاحية ودوالها ورسائل أخطائها بالعربية، ومفسّرها مكتوب بـ **C++17**.
يرافقها محرر أكواد لأندرويد (**Java + XML**) وسير عمل **GitHub Actions** يبني ملف APK تلقائياً.

```
EEsharp/
├── core/        مفسّر EE# بلغة C++ (محلل لفظي ← نحوي ← منفّذ) + واجهة سطر الأوامر
├── android/     محرر الأكواد: Java + XML + جسر JNI إلى المفسّر
├── examples/    برامج تجريبية
├── tests/       اختبارات (برنامج + ناتج متوقع)
└── .github/workflows/android.yml   بناء المفسّر والاختبارات وملف APK
```

## ثلاث علامات تكفي لقراءة أي كود

| الشيء | كيف يُكتب | مثال |
|---|---|---|
| **المفهوم** (دالة أو أمر) | يبدأ بـ `$` | `$اعرض` ، `$جمع` |
| **المتغير** | بين `<<` و `>>` | `<<الاسم>>` |
| **القيمة** | نص بين علامتي اقتباس، أو رقم | `"مرحباً"` ، `٣٫٥` |

وكل كتلة (شرط، حلقة، مفهوم، برنامج) تنتهي بكلمة واحدة: **`نهاية`**، ويُستحسن تسميتها بنوع الكتلة: `نهاية لو` ، `نهاية كرر` ، `نهاية لكل` ، `نهاية مفهوم` ، `نهاية برنامج`.

```
برنامج مثال

// تعليق
متغير <<الاسم>> = "سارة"
$اعرض "أهلاً", <<الاسم>>

مفهوم $مضروب(<<ن>>)
  لو <<ن>> اصغر من او يساوي 1
    ارجع 1
  نهاية لو
  ارجع <<ن>> * $مضروب(<<ن>> - 1)
نهاية مفهوم
$اعرض $مضروب(5)          // 120

لو <<الاسم>> = "سارة"
  $اعرض "مرحباً سارة"
والا لو <<الاسم>> = "أحمد"
  $اعرض "مرحباً أحمد"
والا
  $اعرض "من أنت؟"
نهاية لو

متغير <<ن>> = 0
كرر <<ن>> اصغر من 3
  <<ن>> += 1
نهاية كرر

لكل <<ع>> في [3، 1، 2]
  $اعرض <<ع>>
نهاية لكل

نهاية برنامج
```

### قواعد الكتابة

- **كل جملة في سطر.** وللجمل القصيرة على سطر واحد افصل بينها بـ `؛` : `متغير <<أ>> = 1؛ متغير <<ب>> = 2`.
- **الأمر بلا أقواس:** `$اعرض "نص", <<س>>` ، أو بأقواس مع إمكانية التداخل: `$اعرض($جمع(1, 2))`.
- **التعريف:** `متغير <<س>> = 5` ثم الإسناد `<<س>> = 6` أو `<<س>> += 1`.
- **المفهوم:** `مفهوم $جمع(<<أ>>, <<ب>>)` أو بلا أقواس `مفهوم $جمع <<أ>>, <<ب>>` ... `نهاية`.
  يمكن تمرير المفهوم كقيمة بكتابته بلا أقواس: `متغير <<ف>> = $جمع` ثم `<<ف>>(1, 2)`.
- **مفهوم مجهول:** `متغير <<مربع>> = مفهوم(<<س>>) ارجع <<س>> * <<س>> نهاية`.
- **غلاف البرنامج (اختياري):** `برنامج الاسم` في البداية و`نهاية` في آخر الملف، فتصبح بداية الكود ونهايته واضحتين.
- **النهايات المسمّاة:** التسمية اختيارية لكن اللغة تتحقق منها: `نهاية كرر` على كتلة `لو` خطأ واضح يذكر الكتلة المفتوحة وسطرها. وفي سلسلة `لو ... والا لو ... والا` نهاية واحدة `نهاية لو` تغلقها كلها.
- **الأخطاء المفيدة:** إذا نسيت العلامة تخبرك الرسالة بالصيغة الصحيحة، وإن نسيت `نهاية` تذكر أي كتلة (وفي أي سطر) لم تُغلق وما النهاية المطلوبة.

### الكلمات المفتاحية

| الكلمة | المعنى |
|---|---|
| `متغير` | تعريف متغير |
| `لو` (أو `اذا`) / `والا لو` / `والا` | شرط. السلسلة كلها تنتهي بـ `نهاية` واحدة |
| `كرر` (أو `طالما`) | حلقة while |
| `لكل <<س>> في ...` | حلقة على قائمة أو نص |
| `مفهوم` (أو `دالة`، `وظيفة`) | تعريف مفهوم (دالة) |
| `ارجع` | إرجاع قيمة |
| `توقف` / `استمر` | break / continue |
| `صح` `خطأ` `عدم` | true / false / null |
| `و` `او` `ليس` | and / or / not |
| `برنامج` ... `نهاية` | غلاف البرنامج (أو `ابدأ` ... `انتهى`) |
| `صنف` / `يرث` | تعريف صنف ووراثته (`نهاية صنف`) |

الهمزات اختيارية في الكلمات المفتاحية (`اذا` = `إذا`، `او` = `أو`، `والا` = `وإلا`).

### المقارنة بالكلمات

| بالكلمات | الرمز |
|---|---|
| `<<س>> اكبر من 3` | `<<س>> > 3` |
| `<<س>> اصغر من 3` | `<<س>> < 3` |
| `<<س>> اكبر من او يساوي 3` | `<<س>> >= 3` |
| `<<س>> اصغر من او يساوي 3` | `<<س>> <= 3` |
| `<<س>> = 3` | `<<س>> == 3` |
| `<<س>> لا = 3` أو `<<س>> لا يساوي 3` | `<<س>> != 3` |

و`ليس` تنفي المقارنة كاملة: `ليس <<س>> = 3` تعني `ليس (<<س>> = 3)`. الرموز `== != < > <= >=` تعمل أيضاً، والكلمة `يساوي` ما زالت مقبولة كمرادف للعلامة `=`.

### العلامة `=`: إسناد أم مساواة؟

- **في بداية الجملة** `=` تعني **إسناداً**: `<<س>> = 5` و`<<ق>>[0] = 9` و`متغير <<س>> = 5`.
- **داخل أي تعبير** (شرط، وسيط، قيمة) `=` تعني **مساواة**: `لو <<س>> = 5` و`$اعرض <<س>> = 5` و`كرر <<ن>> = 0`.
- وبعد علامة الإسناد يُقرأ الباقي تعبيراً، فـ `<<س>> = <<أ>> = <<ب>>` تعني: ضع في `<<س>>` نتيجة مقارنة `<<أ>>` بـ `<<ب>>`.

### رموز الحساب والإسناد

| الرمز | معناه | مثال |
|---|---|---|
| `+` `-` `*` `/` `%` | جمع، طرح، ضرب، قسمة، باقي | `<<س>> + 1` |
| `×` `÷` `−` `٪` | ضرب، قسمة، طرح، باقي (بدائل رياضية) | `٦ × ٧` ، `<<س>> ÷ 4` |
| `≠` `≤` `≥` | `!=` و`<=` و`>=` | `<<س>> ≥ 16` |
| `=` ، `←` | إسناد في بداية الجملة | `<<س>> = 5` ، `<<س>> ← 5` |
| `+=` `-=` `*=` `/=` `%=` | إسناد مركّب | `<<س>> += 1` |
| `×=` `÷=` `−=` `٪=` | إسناد مركّب بالرموز الرياضية | `<<س>> ×= 2` |
| `$` | بداية المفهوم | `$اعرض` |
| `#` | تعليق (مثل `//`) | `# ملاحظة` |

### تفاصيل عربية

- الأرقام العربية الهندية تعمل: `٣ + ٤٫٥`
- الفاصلة العربية `،` والفاصلة المنقوطة `؛` تعملان مثل `,` و `;`
- النصوص: `"..."` أو `'...'` أو `“...”` أو `«...»`
- التعليقات: `// ...` أو `# ...` أو `/* ... */`
- **الشرطة السفلية `_`** تفصل كلمات الاسم الواحد في المتغيرات والمفاهيم: `<<اسم_المستخدم>>` و`<<عدد_المحاولات>>` و`$مجموع_الأعداد`. الأسماء بأي حروف عربية أو لاتينية وأرقام و `_`، وتبدأ بحرف.
  والمسافة داخل `<< >>` غير مسموحة، وتقترح لك الرسالة الاسم الصحيح: `<<اسم المستخدم>>` ← `<<اسم_المستخدم>>`.

### الأنواع والعمليات

أرقام، نصوص، منطقي، قوائم، مفاهيم، عدم. العمليات: `+ - * / %` و `== != < > <= >=` و `+= -= *= /= %=`.
`+` يجمع الأرقام ويدمج النصوص والقوائم، و `"ab" * 3` تكرر النص. الفهرسة تبدأ من 0 ويقبل `<<ق>>[-1]` للأخير.

## الأعداد الكبيرة (بلا حدّ للأرقام)

الأرقام العادية تدقّ حتى ١٥ خانة تقريباً. أما `$كبير` فيعطيك **عدداً صحيحاً بحجم لا يحدّه إلا الذاكرة** (حتى مليون خانة)،
وخلفه في C++ صنف `BigInt` كامل: جمع وطرح، ضرب، **قسمة طويلة**، أسّ سريع، **أسّ بالباقي**، واختبار أولية **Miller–Rabin**.
وكلها تُكتب هنا في أسطر قليلة:

```
متغير <<ناتج>> = $كبير(1)
لكل <<ع>> في $مدى(1, 101)؛ <<ناتج>> *= <<ع>>؛ نهاية لكل
$اعرض "١٠٠! =", <<ناتج>>
$اعرض "عدد خاناته:", $طول($نص(<<ناتج>>))
```

| المفهوم | الوصف |
|---|---|
| `$كبير(x)` | يحوّل رقماً صحيحاً أو نصاً من أرقام إلى عدد كبير |
| `$اس_كبير(أ، ن)` | `أ` مرفوعاً للأس `ن` بدقة كاملة |
| `$اس_بالباقي(أ، ن، م)` | `أ^ن` باقي القسمة على `م` (أساس RSA) دون تضخم الأرقام |
| `$اولي_كبير(x)` | هل العدد أولي؟ |

- العمليات `+ - * / % < > = ...` تعمل عليه وعلى الأرقام الصحيحة العادية؛ والناتج عدد كبير.
- `/` و`%` على الأعداد الكبيرة **قسمة صحيحة** (القاطعة نحو الصفر): `-7 / 2` تعطي `-3` وباقيها `-1`.
- أي رقم صحيح يزيد على ١٥ خانة يُقرأ تلقائياً عدداً كبيراً: `متغير <<س>> = 123456789012345678901234567890`.
- لا يُخلط مع الأرقام العشرية في الحساب (تظهر رسالة تطلب `$كبير`)، ويمكن مقارنته بها. `$رقم(x)` يعيده رقماً عادياً، و`$نوع(x)` يعطي `عدد_كبير`.
- أمثلة جاهزة في `examples/`: `factorial_big.ee` و`digit_sum_pow.ee` و`fibonacci_big.ee` و`mersenne.ee` و`rsa_toy.ee`.

## أقوى مفهوم من ست لغات داخل EE#

اخترنا من كل لغة أصعب ما فيها وأقواه، وأتينا به إلى EE# بصيغته العربية (وكلها مكتوبة في المفسّر بـ C++).

| اللغة | المفهوم | في EE# |
|---|---|---|
| **JavaScript** | دوال من الدرجة الأولى، إغلاقات، دوال سهمية، تركيب وتطبيق جزئي وحفظ النتائج | `<<س>> => <<س>> × 2` ، `$خريطة` `$رشح` `$اختزل` `$رتب_حسب` `$ركب` `$جزئي` `$احفظ` |
| **TypeScript** | أنواع اختيارية تُفحص عند التنفيذ (اتحاد، قوائم، اختياري، أصناف) | `متغير <<ع>>: رقم = 5` ، `مفهوم $جمع(<<أ>>: رقم): رقم` |
| **XML** | محلل كامل + استعلام + كتابة (كيانات، CDATA، تعليقات، سمات، أسماء عربية) | `$حلل_xml` `$ابحث_xml` `$سمة` `$اكتب_xml` |
| **Python** | التوليد (comprehensions) المتداخل بشروط، و zip وenumerate | `[<<س>> × <<س>> لكل <<س>> في ق لو <<س>> > 1]` |
| **C++** | أصناف ووراثة ودوال افتراضية وبانٍ ومناداة الأب | `صنف $كلب يرث $حيوان` |
| **C** | مؤشرات وحساب مؤشرات وذاكرة يدوية مع كشف الأخطاء | `&<<س>>` ، `*<<م>>` ، `$احجز` ، `$حرر` |

(والأعداد الكبيرة من C++ موثّقة في القسم السابق.)

### JavaScript: دوال سهمية وتركيب

```
متغير <<ضعف>> = <<س>> => <<س>> × 2
متغير <<ضرب>> = (<<أ>>, <<ب>>) => <<أ>> × <<ب>>
$اعرض $خريطة([1, 2, 3], $ركب(<<ضعف>>, <<س>> => <<س>> + 1))   // [4، 6، 8]
$اعرض $جزئي(<<ضرب>>, 3)(7)                                      // 21
```

- `$خريطة(ق، f)` و`$رشح(ق، f)` و`$ابحث(ق، f)` و`$اي(ق، f)` و`$كل(ق، f)`: إن كانت `f` تأخذ معاملين وصلها الفهرس أيضاً.
- `$اختزل(ق، f، بداية)` و`$رتب_حسب(ق، f)` (المقارِن يرجع سالباً أو صفراً أو موجباً، والترتيب مستقر).
- `$ركب(f، g)(x)` = `f(g(x))` ، و`$جزئي(f، أ)` يثبّت المعاملات الأولى، و`$احفظ(f)` يحفظ نتائج الاستدعاءات السابقة (يجعل `فيبوناتشي` التراجعية سريعة).
- للمفاهيم الأطول: `مفهوم(<<ن>>) ... نهاية` ، وعند وضعها داخل أقواس اكتب `نهاية)` على سطر وحدها.

### TypeScript: أنواع اختيارية

```
متغير <<عمر>>: رقم او نص = "ثلاثون"
متغير <<ق>>: قائمة[رقم] = [1, 2, 3]
متغير <<ا>>: رقم؟ = عدم                 // اختياري: رقم أو عدم
مفهوم $جمع(<<أ>>: رقم, <<ب>>: رقم): رقم
  ارجع <<أ>> + <<ب>>
نهاية مفهوم
```

الأنواع: `رقم نص منطقي قائمة قائمة[نوع] مفهوم عدم عدد_كبير عدد مؤشر كائن أي` ، واسم أي صنف (`$حيوان` أو `حيوان`)، والاتحاد بـ `او` أو `|` ، والاختياري بـ `؟`.
تُفحص القيمة عند التعريف وعند كل إسناد وعند تمرير المعاملات وعند الإرجاع، فيقول الخطأ أي متغير وما النوعان. (الفحص عند التنفيذ لا قبله.)

### XML

```
متغير <<م>> = $حلل_xml('<مكتبة><كتاب سعر="12">الأيام</كتاب></مكتبة>')
$اعرض $سمة($ابحث_xml(<<م>>, "كتاب")[0], "سعر")        // 12
```

العقدة قائمة `[وسم، سمات، أبناء، نص]` تعمل عليها `$وسم` `$سمات` `$سمة(ع، اسم، افتراضي)` `$ابناء` `$نص_عقدة` .
`$ابحث_xml(ع، "وسم")` يجد كل الأحفاد بهذا الوسم، و`"أ/ب/ج"` مسار أبناء، و`"*"` أي وسم. `$عقدة(وسم، سمات، أبناء، نص)` يبني عقدة و`$اكتب_xml(ع)` يكتبها (ويهرب الرموز) بتنسيق مرتب، أو مضغوطاً إن مرّرت `صح` ثانياً.
أخطاء التحليل تذكر السطر والوسم المطلوب إغلاقه.

### Python: التوليد

```
$اعرض [<<س>> × <<س>> لكل <<س>> في $مدى(1, 11) لو <<س>> ٪ 2 = 0]
$اعرض [[<<أ>>, <<ب>>] لكل <<أ>> في [1, 2] لكل <<ب>> في "xy"]     // متداخل
$اعرض $ضم([1, 2], ["a", "b"]), $ترقيم(["x", "y"], 1), $مجموع([1, 2, 3.5])
```

### C++: الأصناف

```
صنف $حيوان
  متغير <<ارجل>> = 4                       // حقل بقيمة افتراضية
  مفهوم $انشاء(<<اسم>>)                    // البانئ
    <<هذا>>.<<اسم>> = <<اسم>>
  نهاية مفهوم
  مفهوم $تكلم()
    $اعرض <<هذا>>.<<اسم>>, "يصدر صوتاً"
  نهاية مفهوم
نهاية صنف
صنف $كلب يرث $حيوان
  مفهوم $انشاء(<<اسم>>)
    $الاب(<<اسم>>)                         // مناداة بانئ الأب
  نهاية مفهوم
  مفهوم $تكلم()                            // إعادة تعريف (دالة افتراضية)
    $الاب()
    $اعرض "وَوْ!"
  نهاية مفهوم
نهاية صنف
متغير <<ك>>: $حيوان = $كلب("ريكس")
<<ك>>.$تكلم()
```

- الحقل `<<ك>>.<<اسم>>` (علامة المتغير) والمفهوم `<<ك>>.$اسم()` (علامة المفهوم). الإسناد `<<ك>>.<<ارجل>> += 1` يعمل.
- استدعاء الصنف كمفهوم ينشئ كائناً: `$كلب("ريكس")` ، والمفهوم الذي في الأب يُستدعى بـ `$الاب(...)` من الاسم نفسه في الابن.
- المفهوم يُختار بحسب الصنف الحقيقي للكائن (تعدد الأشكال)، و`$نوع(ك)` يعطي اسم الصنف.

### C: المؤشرات والذاكرة

```
مفهوم $بدل(<<أ>>, <<ب>>)
  متغير <<ت>> = *<<أ>>؛ *<<أ>> = *<<ب>>؛ *<<ب>> = <<ت>>
نهاية مفهوم
$بدل(&<<س>>, &<<ص>>)              // تبديل بالمؤشرات

متغير <<م>> = $احجز(5)             // malloc: مؤشر إلى 5 خانات
*(<<م>> + 2) = 99                  // حساب المؤشرات
$حرر(<<م>>)                        // free
```

- `&<<س>>` عنوان متغير أو `&<<ق>>[1]` عنصر أو `&<<ك>>.<<حقل>>` حقل، و`*م` يقرأ، و`*م = قيمة` يكتب (و`*م += 1` أيضاً).
- حساب المؤشرات على مؤشرات القوائم: `م + ن` و`م - ن` و`م - م` والمقارنة. و`عدم` هو NULL.
- أخطاء بأسماء مألوفة: فكّ مؤشر `عدم` (خطأ تجزئة)، الوصول خارج الحدود أو بعد التحرير، وتحرير مضاعف (double free).

## صفحة ويب كاملة بـ EE#

برنامج EE# يطبع صفحة HTML كاملة (RTL وجوال ووضع داكن تلقائي وتنسيق جاهز) من دون كتابة سطر HTML واحد:

```
متغير <<مواد>> = ["الرياضيات", "العلوم"]
متغير <<درجات>> = [92, 85]
$اعرض $صفحة("نتائجي",
  $بطل("نتائج الفصل", "مكتوبة بلغة EE#"),
  $رئيسي($بطاقة("الدرجات", $جدول(["المادة", "الدرجة"], $ضم(<<مواد>>, <<درجات>>))),
         $رسم_اعمدة(<<مواد>>, <<درجات>>)))
```

شغّله ثم **احفظ المخرجات** باسم `index.html` (في سطر الأوامر: `ee page.ee > index.html`)، أو اضغط **🌐 معاينة** في المحرر لترى الصفحة فوراً وتحفظها بزر «حفظ HTML».

| المفهوم | الناتج |
|---|---|
| `$صفحة(عنوان، محتوى...)` | المستند كاملاً: `<html lang="ar" dir="rtl">` وتنسيق وعنوان |
| `$بطل(عنوان، وصف)` ، `$تنقل([[نص، رابط]...])` | واجهة علوية ، شريط تنقل |
| `$رئيسي` `$قسم` `$مقال` `$رأس` `$تذييل` `$حاوية` `$شبكة` `$بطاقة(عنوان، ...)` | هيكل الصفحة |
| `$عنوان(نص، مستوى)` `$فقرة` `$ابراز` `$مائل` `$كود` `$كتلة_كود` `$اقتباس` `$صغير` | النصوص |
| `$رابط(نص، عنوان)` `$صورة(مصدر، وصف)` `$زر(نص، js)` `$سطر_جديد()` `$فاصل()` | روابط ووسائط |
| `$قائمة_نقطية(ق)` `$قائمة_مرقمة(ق)` `$جدول(رؤوس، صفوف)` | قوائم وجداول |
| `$نموذج(...)` `$حقل(اسم، تسمية، نوع)` | نماذج (النوع `textarea` لمنطقة نص) |
| `$رسم_اعمدة(تسميات، قيم)` | رسم بياني SVG متجاوب |
| `$صنف_css(اسم، عنصر)` `$نمط(css، عنصر)` `$معرف(id، عنصر)` | إضافة صفة لعنصر جاهز |
| `$اسلوب(css)` `$سكربت(js)` `$خام(html)` `$وسم_html(وسم، صفات، ...)` | حرية كاملة عند الحاجة |

- **أمان:** أي نص عادي تمرّره يُهرَّب تلقائياً (`<` تصبح `&lt;`)، فلا يمكن حقن HTML من مدخلات المستخدم. والعناصر المبنية بالمفاهيم تُدرج كما هي، والقوائم تُسطَّح، و`عدم` يُتجاهل. روابط `javascript:` تُستبدل بـ `#`.
- لإدراج HTML جاهز اعتمده صراحةً بـ `$خام("...")`.
- الصفات تُكتب أزواجاً: `$وسم_html("div", [["class", "x"], ["hidden", صح]], "محتوى")`.
- التنسيق الافتراضي يتكيّف مع وضع الجهاز الفاتح/الداكن ويمكن تعديله بـ `$اسلوب("...")` داخل الصفحة.

## تطبيق أندرويد

محرر بتلوين للصيغة، وخانة مدخلات، وزرا تشغيل وإيقاف، وفتح/حفظ الملفات، وحفظ تلقائي. لا يعتمد على أي مكتبات خارجية.

- **شريط الرموز:** أزرار لإدراج `$` و`<< >>` و`" "` (يوضع المؤشر داخلها تلقائياً) والكلمات المفتاحية.
- **إغلاق تلقائي:** كتابة `(` أو `[` أو `"` أو `<<` تضيف المغلِق وتضع المؤشر بينهما، وكتابة المغلِق فوق مغلِق موجود تتخطّاه بدل تكراره (لا تتكرر `)` ولا `>>`).
- **نهاية تلقائية:** عند ضغط Enter بعد سطر يفتح كتلة (`لو` أو `كرر` أو `لكل` أو `مفهوم`) تُضاف الإزاحة وتُكتب تحتها `نهاية لو` (أو نوع الكتلة)، والمؤشر في مكانه داخل الجسم. ولا تُكرَّر إن كانت النهاية موجودة أصلاً.
- **معاينة الويب:** زر «🌐 معاينة» يعرض الصفحة التي أنتجها البرنامج في عارض مدمج ويحفظها ملف HTML.
- **تنسيق:** زر «تنسيق» يرتّب إزاحة الكود حسب الكتل ويسمّي كل `نهاية` عارية بنوع كتلتها.
- **سمتان:** فاتحة بخلفية دافئة هادئة، وداكنة بألوان ناعمة. زر «◐ السمة» للتبديل ويُحفظ اختيارك.
- **تلوين:** كل نوع بلون: المفاهيم `$` والمتغيرات `<< >>` والنصوص والأرقام والكلمات المفتاحية؛ والفواصل باهتة والتعليقات خافتة.

- **من GitHub:** ادفع المشروع إلى مستودع. تبني الـ Action ملف APK وتجده في صفحة التشغيل ضمن *Artifacts*. وعند دفع وسم مثل `v0.1.0` يُرفق الملف تلقائياً بصفحة *Releases*.
- **محلياً:** افتح مجلد `android/` في Android Studio (سينشئ Gradle wrapper تلقائياً) وشغّل `app`.
  أو من سطر الأوامر مع Gradle 8.7 وJDK 17 وNDK 26: `cd android && gradle assembleDebug`.

> الـ APK الناتج من `assembleDebug` موقّع بمفتاح التطوير ويُثبَّت مباشرة على الهاتف. للنشر على المتاجر أضف إعداد توقيع Release.

## لغة كاملة: الأخطاء والوحدات والملفات (الإصدار 0.2)

**معالجة الأخطاء**
```
حاول
  $اعرض $قسم(1, 0)
امسك <<خ>>            // <<خ>> = القيمة المرمية أو رسالة خطأ النظام
  $اعرض "خطأ:", <<خ>>, "في السطر", $سطر_الخطأ()
اخيرا                  // تُنفَّذ دائماً، حتى مع ارجع/توقف/خطأ
  $اعرض "تنظيف"
نهاية حاول
```
- `$ارم(قيمة)` يرمي أي قيمة (نص، قائمة...)؛ بلا `امسك` يستمر الخطأ بعد `اخيرا`.
- أخطاء النظام (قسمة على صفر، فهرس خارج النطاق، نوع خاطئ...) قابلة للالتقاط. إيقاف البرنامج من المحرّر لا يُلتقط.

**الوحدات والملفات** (تعمل من سطر الأوامر؛ معطّلة في تطبيق الجوال للأمان)
| الدالة | الوظيفة |
|---|---|
| `$استورد("مسار.ee")` | تحميل ملف EE# مرة واحدة (المسار نسبةً لمجلد الملف المستورِد) |
| `$اقرأ_ملف` `$اسطر_ملف` | قراءة نص / قائمة أسطر |
| `$اكتب_ملف` `$الحق_ملف` | كتابة / إلحاق |
| `$يوجد_ملف` `$احذف_ملف` | فحص / حذف |
| `$وسائط()` | وسائط سطر الأوامر: `ee برنامج.ee أ ب` |
| `$اخرج(رمز)` | إنهاء البرنامج برمز خروج |
| `$متغير_بيئة("اسم")` | قراءة متغير بيئة |

**الأداء**: مسارات سريعة للأرقام وتخزين مفاتيح البحث (≈20% أسرع). المفسّر ما زال شجرياً؛ الآلة الافتراضية (بايت‌كود) خطوة مستقبلية.

## ألوان بلا حدود
كل مكوّن لوني يقبل **أي لون**: `"#ff512f"` أو `"#abc"` أو `"rgb(10,20,30)"` أو `"hsl(200,80%,50%)"` أو اسماً عربياً (احمر، ذهبي، كحلي، عنابي، تركوازي، زمردي…) أو اسماً لاتينياً (`gold`)، أو ناتج `$لون_rgb`/`$لون_hsl`.
- `$خلفية_متدرجة(لون أو [لون1، لون2، لون3...]، محتوى...)` و`$بطاقة_متدرجة(عنوان، وصف، لون أو [ألوان])` — حتى 12 لوناً في التدرج؛ يُختار لون النص (فاتح/داكن) تلقائياً.
- `$لون_الموقع(لون، محتوى...)` تلوّن كل الأزرار والأشرطة داخلها بلون واحد.
- `$زر_ملون(نص، لون، رابط)` `$شارة_ملونة(نص، لون)` `$نص_ملون(نص، لون)` `$نص_متدرج(نص، لون1، لون2)`.
- أي لون غير صالح يُرفض برسالة خطأ (لا يُسمح بإدخال شيفرة عبر الألوان).
